# MyDoctorNow (MedicalAppointmentWebApp)

Το **MyDoctorNow** είναι μια διαδικτυακή εφαρμογή (Web Application) για τη διαχείριση και την ηλεκτρονική κράτηση ιατρικών ραντεβού. Αναπτύχθηκε με βάση τη μεθοδολογία Agile Scrum και επιτρέπει στους ασθενείς να αναζητούν διαθέσιμους ιατρούς και να κλείνουν ραντεβού, ενώ παρέχει στους ιατρούς τα απαραίτητα εργαλεία για την οργάνωση των ιατρείων και του προγράμματός τους.

---

## Βασικές Λειτουργίες & Ρόλοι Χρηστών

Στο σύστημα υποστηρίζονται τέσσερις διακριτοί ρόλοι χρηστών:

* **Επισκέπτης (Visitor):**
  * Αναζήτηση ιατρών βάσει ονόματος, ειδικότητας ή/και περιοχής.
  * Φιλτράρισμα αποτελεσμάτων (φύλο ιατρού, χιλιομετρική ακτίνα αναζήτησης) και ταξινόμηση (αλφαβητικά ή βάσει πρώτου διαθέσιμου ραντεβού).
  * Προβολή επαγγελματικού προφίλ ιατρού και διαθέσιμων ωρών.
  * Εγγραφή στο σύστημα ως Ασθενής ή Ιατρός (μέσω Email ή λογαριασμού Google).

* **Ασθενής (Patient):**
  * Σύνδεση (μέσω Email ή Google), επαναφορά κωδικού πρόσβασης και επεξεργασία προφίλ.
  * Προγραμματισμός ραντεβού σε διαθέσιμη ημέρα και ώρα.
  * Λήψη μοναδικού αναγνωριστικού **QR Code** (στην εφαρμογή και μέσω email) για την επιβεβαίωση της επίσκεψης.
  * Προβολή ιστορικού/επερχόμενων ραντεβού και δυνατότητα ακύρωσης προγραμματισμένου ραντεβού.

* **Ιατρός (Doctor):**
  * Προσθήκη και επεξεργασία ενός ή περισσότερων ιατρείων (διεύθυνση, τηλέφωνο, διάρκεια ραντεβού, ημέρες και ώρες λειτουργίας).
  * Προβολή ημερολογίου κρατήσεων και διαθεσιμότητας σε μηνιαία και ημερήσια μορφή.
  * Διαχείριση ραντεβού (ακύρωση ή σήμανση ως «Απών»).
  * Ολοκλήρωση ραντεβού μέσω **σάρωσης του QR Code** του ασθενή (με χρήση κάμερας ή με ανέβασμα αρχείου εικόνας).

* **Διαχειριστής (Administrator):**
  * Έλεγχος και έγκριση ή απόρριψη των αιτήσεων εγγραφής νέων ιατρών.
  * Έλεγχος και έγκριση ή απόρριψη των αιτήσεων καταχώρησης νέων ιατρείων.

## Τεχνολογίες Υλοποίησης

* **Backend:** ASP.NET MVC, C#, Entity Framework (με χρήση Repository & Service Layer pattern)
* **Βάση Δεδομένων:** Microsoft SQL Server Express
* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Αυθεντικοποίηση & Ασφάλεια:** JWT (JSON Web Tokens), Google OAuth 2.0
* **Εξωτερικές Υπηρεσίες (APIs):**
  * **Google Maps & Google Places API:** Εύρεση τοποθεσίας και υπολογισμός ακτίνας αναζήτησης.
  * **Maileroo (SMTP):** Αποστολή αυτοματοποιημένων ενημερωτικών email (εγγραφές, κρατήσεις, ακυρώσεις, επαναφορά κωδικού, εγκρίσεις διαχειριστή).

## Οδηγίες Εγκατάστασης

### 1. Προαπαιτούμενα
* Εγκατάσταση του **Visual Studio**.
* Εγκατάσταση του **Microsoft SQL Server Express**.

### 2. Παραμετροποίηση Project (User Secrets)
1. Ανοίξτε το αρχείο `.slnx` του project (`MedicalAppointmentWebApp.slnx`) στο Visual Studio.
2. Στο Solution Explorer, κάντε δεξί κλικ πάνω στο project και επιλέξτε **"Manage User Secrets"**.
3. Προσθέστε την παρακάτω δομή στο αρχείο `secrets.json` συμπληρώνοντας τα αντίστοιχα κλειδιά σας:

```json
{
  "SecretKey": "secretKey",
  "Issuer": "MedicalAppointmentWebApp",
  "Audience": "MedicalAppointmentUser",
  "Maileroo": {
    "email": "your maileroo email",
    "password": "your maileroo password"
  },
  "Google": {
    "ClientId": "client id",
    "ClientSecret": "client secret"
  }
}
```

### 3. Ρύθμιση Βάσης Δεδομένων
1. Δημιουργήστε μια βάση δεδομένων στον SQL Server Express με το όνομα **`medappdb`**.
2. Μέσα στο Visual Studio, ανοίξτε το **Package Manager Console** (`Tools` -> `NuGet Package Manager` -> `Package Manager Console`).
3. Εκτελέστε την παρακάτω εντολή για την εφαρμογή των Migrations:

```powershell
Update-Database
```

4. Εκτελέστε την εφαρμογή πατώντας το κουμπί **Run (https)** ή το πλήκτρο `F5`.
